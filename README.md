An entry for make.fun's "Make the Judge Smile" bounty. `main.py` (Python 3.13, stdlib only) deterministically writes a single line, under 200 characters, about a small good thing that happened today: a baker's burnt croissant and the moment of realising you've quietly become a regular. The output goes to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
